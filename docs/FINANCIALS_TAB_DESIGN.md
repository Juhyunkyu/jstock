# 재무제표 탭 UI/UX 설계서

> 버전: v1.0 | 작성일: 2026-03-23
> 상태: 설계 단계 (코드 미작성)

---

## 1. 개요

### 1.1 목표
현재 티커 상세 페이지(`/index/:symbol`)는 차트만 제공한다.
**차트 | 재무** 탭 구조로 변경하여, 개인 투자자가 기업의 재무 건전성과 밸류에이션을
한눈에 파악할 수 있는 재무제표 탭을 추가한다.

### 1.2 타겟 사용자
- 주식 투자 초보~중급 개인 투자자
- 전문 용어에 익숙하지 않은 일반인도 이해 가능해야 함
- 모바일 우선, 데스크톱에서도 활용

### 1.3 디자인 철학
| 원칙 | 설명 |
|------|------|
| 초보자 친화 | 모든 전문 용어에 설명 아이콘 제공 |
| 시각적 우선 | 숫자 나열 대신 차트/그래프/색상으로 표현 |
| 점진적 공개 | 핵심 지표 먼저, 상세는 탭/확장으로 |
| 모바일 퍼스트 | 카드 기반 세로 스크롤, 가로 스크롤 최소화 |
| 다크모드 완전 대응 | `context.app*` 색상 체계 100% 준수 |

### 1.4 벤치마크 분석 요약

| 앱 | 핵심 특징 | 차용할 점 |
|----|-----------|-----------|
| **토스증권** | 정보 계층화, 초보자 친화, 카드 UI, 상승/하락 빨강/파랑 | 설명 툴팁, 카드 기반 레이아웃, 색상 규칙 |
| **네이버증권** | 테이블 중심, 연간/분기 토글, 매출/영업이익/순이익 추이 | 분기/연간 토글, 실적 추이 막대 차트 |
| **Yahoo Finance** | 탭 분리(Income/Balance/Cash), 연간/분기 토글, 40년 히스토리 | 탭 구조, 기간 선택 |
| **Robinhood** | 카드 기반, 점진적 공개, 색상으로 상태 표현, 최소 정보 → 상세 확장 | 카드 확장 패턴, 색상 코딩 |

## 2. 페이지 구조 변경

### 2.1 탭 전환 구조

현재 `IndexDetailScreen`의 `SingleChildScrollView` 내부 구조를 **TabBar** 기반으로 변경한다.

```
AppBar: [<- 뒤로] [종목명]              [$현재가] [+1.25%] [새로고침]
TabBar: [ 차트 ] [ 재무 ]
─────────────────────────────────────────────────────────
TabBarView:
  Tab 0 (차트): 기존 차트/피벗/설명/뉴스 그대로
  Tab 1 (재무): 새로 추가할 재무제표 화면
```

- TabBar는 AppBar 하단에 고정 (SliverAppBar + pinned TabBar)
- 탭 전환 시 스와이프 지원 (단, 차트 탭에서 드로잉 모드일 때는 비활성)
- 재무 탭 진입 시 lazy loading (탭 클릭 시점에 API 호출)

### 2.2 적용 범위
- **개별 종목** (AAPL, MSFT 등): 재무 탭 표시
- **지수** (^NDX, ^GSPC): 재무 탭 숨김 (지수는 재무제표 없음)
- 판별: `symbol.startsWith('^')` 이면 탭 없이 기존 구조 유지

## 3. 데이터 소스 (API)

### 3.1 Finnhub (무료 티어, 이미 사용 중)

| 엔드포인트 | 용도 | 주요 필드 |
|-----------|------|-----------|
| `GET /stock/profile2?symbol=` | 기업 개요 | `name`, `finnhubIndustry`, `marketCapitalization`, `shareOutstanding`, `ipo`, `logo`, `weburl`, `country`, `exchange` |
| `GET /stock/metric?symbol=&metric=all` | 주요 지표 | `metric.pe`, `metric.pb`, `metric.roe`, `metric.roa`, `metric.currentRatio`, `metric.totalDebtToEquity`, `metric.netMargin`, `metric.grossMargin`, `metric.beta`, `metric.dividendYieldIndicatedAnnual` |
| `GET /stock/metric?symbol=&metric=all` | 시계열 지표 | `series.annual.{pe,pb,roe,roa,eps,...}`, `series.quarterly.{peTTM,roeTTM,...}` |
| `GET /stock/earnings?symbol=` | EPS 실적 | `actual`, `estimate`, `surprise`, `surprisePercent`, `period` |

### 3.2 API 호출 전략
- **캐싱**: 재무 데이터는 변동이 느리므로 **24시간 메모리 캐시**
- **호출 시점**: 재무 탭 최초 클릭 시 (lazy load)
- **병렬 호출**: profile2 + metric + earnings 3개 동시 요청
- **에러 처리**: 부분 실패 허용 (profile 실패해도 metric은 표시)
- **Rate Limit**: Finnhub 무료 30 calls/sec — 3개 동시 호출 충분

### 3.3 ETF/지수 제외 로직
```
if symbol starts with '^'    -> 탭 자체 숨김
if finnhubIndustry == null    -> "재무 정보 없음" 안내 카드
if metric response empty      -> "데이터 준비 중" 안내 카드
```

## 4. 섹션별 상세 설계

### 4.1 기업 개요 섹션

#### 와이어프레임 (모바일 375px)
```
+-----------------------------------------------+
|  [LOGO]  Apple Inc.                            |
|          Technology · NASDAQ · 미국              |
+-----------------------------------------------+
|  시가총액          |  발행주식수                   |
|  $3.45T           |  15.2B 주                    |
|  ─────────────────|───────────────────────────  |
|  IPO 날짜          |  베타                        |
|  1980-12-12       |  1.24                        |
+-----------------------------------------------+
```

#### 디자인 상세
- **레이아웃**: 카드 1개, 상단 헤더 + 하단 2x2 그리드
- **헤더 영역**: 로고(40x40 원형) + 회사명(bold 16px) + 부제(섹터 · 거래소 · 국가, hint 색상 13px)
- **그리드 영역**: 2열 그리드, 각 셀에 라벨(hint 12px) + 값(primary bold 15px)
- **시가총액 포맷**:
  - 1T 이상: `$3.45T`
  - 1B 이상: `$245.6B`
  - 1M 이상: `$890.2M`
- **로고 없을 때**: 회사명 첫 글자 아이콘 (CircleAvatar + 배경색)
- **데스크톱(>=768px)**: 2x2 그리드 -> 1x4 가로 배치

#### 색상 규칙
| 요소 | 라이트 | 다크 |
|------|--------|------|
| 카드 배경 | `context.appCardBackground` | `context.appCardBackground` |
| 회사명 | `context.appTextPrimary` | `context.appTextPrimary` |
| 부제 | `context.appTextHint` | `context.appTextHint` |
| 라벨 | `context.appTextSecondary` | `context.appTextSecondary` |
| 값 | `context.appTextPrimary` | `context.appTextPrimary` |
| 구분선 | `context.appDivider` | `context.appDivider` |

#### 색상 코딩 규칙 (지표 상태 표현)

**지표별 해석 색상** (프로그레스 바 + 보조 텍스트):
| 상태 | 색상 | 적용 기준 예시 |
|------|------|---------------|
| 양호 | `AppColors.green500` | ROE > 15%, PER 적정 범위, 부채비율 < 100% |
| 주의 | `AppColors.amber500` | ROE 5~15%, PER 다소 높음, 부채비율 100~200% |
| 위험 | `AppColors.red500` | ROE < 5%, PER 매우 높음, 부채비율 > 200% |
| 중립 | `context.appTextHint` | 데이터 부족 또는 업종 평균 없을 때 |

**PER/PBR 상태 판별 로직**:
```
PER:
  < 0        -> "적자" (red)
  0 ~ 10     -> "저평가" (green)
  10 ~ 25    -> "적정" (amber 없음, 중립)
  25 ~ 50    -> "다소 높음" (amber)
  > 50       -> "고평가" (red)

부채비율:
  < 50%      -> "매우 건전" (green)
  50 ~ 100%  -> "건전" (green)
  100 ~ 200% -> "보통" (amber)
  > 200%     -> "높음" (red)

ROE:
  < 0        -> "적자" (red)
  0 ~ 5%     -> "낮음" (amber)
  5 ~ 15%    -> "보통" (중립)
  > 15%      -> "우수" (green)
```

#### 프로그레스 바 디자인
- 높이: 6px, 라운드: 3px
- 배경: `context.appDivider`
- 게이지: 상태 색상 (green/amber/red)
- 업종 평균 마커: 세로 점선 (해당 위치에 `|` 표시, 2px 흰색/다크회색 선)
- **업종 평균 비교**: Finnhub은 업종 평균을 직접 제공하지 않으므로 **v1에서는 프로그레스 바만 표시**, 업종 비교는 v2에서 별도 데이터소스 추가 시 구현

#### 데스크톱 레이아웃 (>=768px)
- 기본 지표 6개를 2열 그리드로 배치 (3행 x 2열)
- "더 보기" 확장 시 추가 지표도 2열 그리드

#### 실적 추이 막대 차트 디자인

**데이터 소스**: Finnhub `basic-financials` 시계열 (`series.annual`, `series.quarterly`)
- `revenue` (매출) -> series에 직접 없음 -> `salesPerShare * shareOutstanding`으로 계산하거나
- **대안**: Finnhub `financials-reported` 엔드포인트 (SEC 원본) 또는 Twelve Data income_statement (유료)
- **v1 현실적 접근**: Finnhub 무료 티어에서 확보 가능한 `eps`, `grossMargin`, `netMargin` 시계열을 활용

**v1에서 표시할 시계열 차트**:
| 차트 | 데이터 | 표현 |
|------|--------|------|
| EPS 추이 | `series.quarterly.eps` (최근 8분기) | 막대 차트 |
| EPS Beat/Miss | `earnings` 엔드포인트 (`actual` vs `estimate`) | 라인+도트 오버레이 |
| 수익성 추이 | `series.quarterly.netMargin` (최근 8분기) | 라인 차트 |
| 밸류에이션 추이 | `series.quarterly.peTTM` (최근 8분기) | 라인 차트 |

#### 분기/연간 토글
- `SegmentedButton` 또는 `ToggleButtons` (기존 앱 스타일에 맞춤)
- 분기: 최근 8분기 (2년)
- 연간: 최근 4년

#### 차트 칩 토글 (매출/영업이익/순이익 선택)
- `ChoiceChip` 가로 스크롤
- 선택된 칩: `context.appAccent` 배경 + 흰색 텍스트
- 비선택 칩: `context.appCardBackground` 배경 + `context.appTextSecondary`

#### 막대 차트 디자인 규칙
| 요소 | 라이트 | 다크 |
|------|--------|------|
| 양수 막대 | `AppColors.blue500` (opacity 0.8) | `AppColors.blue400` (opacity 0.8) |
| 음수 막대 | `AppColors.red500` (opacity 0.8) | `AppColors.red400` (opacity 0.8) |
| 축/라벨 | `context.appTextHint` (12px) | `context.appTextHint` (12px) |
| 그리드선 | `context.appDivider` (0.5px) | `context.appDivider` (0.5px) |
| 배경 | 투명 (카드 배경 상속) | 투명 (카드 배경 상속) |

- 막대 너비: 전체 너비 / (데이터 수 * 2) — 막대 간 간격 = 막대 너비
- 막대 상단 라운드: 4px
- 막대 탭 시: 해당 분기 값 + YoY 변화율 표시 (작은 말풍선)

#### EPS Beat/Miss 차트 디자인
- 실제 EPS: 실선 + 원형 도트 (파랑 `AppColors.blue500`)
- 예상 EPS: 점선 + 빈 원 도트 (회색 `context.appTextHint`)
- Beat 도트: 초록 배경 원 (`AppColors.green500`)
- Miss 도트: 빨강 배경 원 (`AppColors.red500`)
- 범례: 차트 우상단에 "● 실제  ○ 예상" (12px)

#### 데스크톱 레이아웃 (>=768px)
- 실적 추이 차트와 EPS 차트를 가로 2열 배치
- 각 차트 최소 높이: 200px

### 4.4 기업 설명 / AI 요약 섹션

#### 와이어프레임 (모바일 375px)
```
+-----------------------------------------------+
|  기업 분석 요약                                  |
+-----------------------------------------------+
|                                                |
|  Apple Inc.은 Technology 섹터에 속하며,          |
|  1980년 상장 이후 꾸준히 성장해온 기업입니다.      |
|                                                |
|  주요 지표 해석:                                 |
|  - PER 28.5배로 업종 대비 다소 높은 편이며,       |
|    시장이 향후 성장을 기대하고 있음을 의미합니다.   |
|  - ROE 35.2%로 매우 우수한 자본 효율성을          |
|    보여주고 있습니다.                             |
|  - 부채비율 176%로 다소 높지만 현금 창출력이       |
|    우수하여 관리 가능한 수준입니다.                 |
|                                                |
|  ⚠ 이 분석은 AI가 자동 생성한 참고 정보이며,      |
|    투자 권유가 아닙니다.                          |
+-----------------------------------------------+
```

#### 설계 원칙
- **템플릿 기반 자동 생성** (LLM API 호출 아님)
- 수집된 지표값을 사전 정의된 문장 템플릿에 삽입
- 예: `"PER {value}배로 {interpretation}"` 형식

#### 템플릿 규칙
```
섹터 소개:
  "{name}은(는) {finnhubIndustry} 섹터에 속하며, {ipo}년 상장된 기업입니다."

PER 해석:
  < 0:   "현재 적자 상태로 PER을 산출할 수 없습니다."
  0~15:  "PER {v}배로 저평가 구간에 있어 가치투자 관점에서 매력적일 수 있습니다."
  15~25: "PER {v}배로 적정 수준의 밸류에이션입니다."
  25~50: "PER {v}배로 시장이 향후 성장을 기대하고 있음을 의미합니다."
  > 50:  "PER {v}배로 높은 편이며, 기대에 부합하는 실적이 필요합니다."

ROE 해석:
  < 0:   "ROE가 음수로 순손실 상태입니다."
  0~10:  "ROE {v}%로 수익성이 낮은 편입니다."
  10~20: "ROE {v}%로 양호한 수익성을 보이고 있습니다."
  > 20:  "ROE {v}%로 매우 우수한 자본 효율성을 보여주고 있습니다."

부채비율 해석:
  < 50:  "부채비율 {v}%로 매우 건전한 재무구조입니다."
  50~100:"부채비율 {v}%로 안정적인 재무구조입니다."
  100~200:"부채비율 {v}%로 다소 높지만 관리 가능한 수준입니다."
  > 200: "부채비율 {v}%로 높은 편이며, 부채 관리에 주의가 필요합니다."
```

#### 주의 문구 (필수)
카드 하단에 항상 표시:
- 텍스트: "이 분석은 재무 데이터를 기반으로 자동 생성된 참고 정보이며, 투자 권유가 아닙니다."
- 스타일: `context.appTextHint`, 12px, 앞에 삼각 경고 아이콘

## 10. 성능 고려사항

| 항목 | 전략 |
|------|------|
| Lazy Loading | 재무 탭 클릭 전까지 API 호출 없음 |
| 메모리 캐시 | 24시간 TTL, 심볼별 캐시 (`Map<String, CachedData>`) |
| 차트 렌더링 | CustomPainter 사용 (외부 차트 라이브러리 미사용, 기존 패턴 유지) |
| 이미지 최적화 | 회사 로고 캐싱 (`CachedNetworkImage` 또는 메모리 캐시) |
| 번들 크기 | 외부 차트 라이브러리 추가 없음 — 순수 CustomPainter |
| 데이터 파싱 | isolate 불필요 (JSON 크기 작음, ~5KB 이하) |
